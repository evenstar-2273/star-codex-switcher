# Star Codex Switcher

面向 Windows 的 Codex 账号管理与切换工具。支持账号额度查看、JSON 导入和安装版更新，只维护 Codex 场景。

[GitHub 下载最新版](https://github.com/evenstar-2273/star-codex-switcher/releases/latest/download/Star-Codex-Switcher-Setup-x64.exe) · [问题反馈](https://github.com/evenstar-2273/star-codex-switcher/issues) · [更新记录](CHANGELOG.md) · [构建与发布](docs/windows-build-release.md)

应用提供原生 Windows 界面，账号数据保存在本机，切换前检查目标凭据并要求二次确认。

## 功能

- 管理多个 ChatGPT 登录账号，切换前二次确认，并检查目标凭据是否可用。
- 当前使用的账号也可删除，确认后仅移除工具保存的账号，保留 Codex 当前登录；刷新或重启不会自动加回，可在“添加账号”中获取本地账号、授权或导入重新添加。
- 显示剩余额度、恢复时间、订阅有效期和重置次数；恢复时间后用括号显示剩余倒计时，额度与临近到期状态用不同颜色区分。
- 优先显示当前登录信息中尚未到期的订阅期末；缺失或过期后通过官方接口查询，无法确认时显示“待核验”。
- 根据账号接口返回的额度窗口显示 5 小时或每周额度，兼容只返回周额度的账号。
- 支持调整窗口大小；账号卡片按可用宽度自动增减列数，切换、刷新、重置和删除直接放在列表中。
- 当前使用的账号固定排在第一位，切换成功后更新显示顺序，其余账号顺序保持不变。
- 手动全量刷新时，顶部与所有卡片的刷新图标旋转；单卡刷新仅旋转对应图标，实际请求完成或失败后停止，防止重复请求并保持滚动位置。
- 刷新失败保留上次额度，在卡片直接说明代理连接、网络超时、登录失效、权限拒绝或请求限流，避免将未知额度显示为 0。登录明确失效时突出红色提示、禁用切换，并提供恢复登录入口。
- 额度自动刷新默认每 5 分钟，可选禁用、2、5、10、15 分钟或自定义 1–1440 分钟；设置即时生效、重启保留，驻留托盘时继续执行；定时刷新静默更新数据，手动刷新保留加载动效。
- FREE、PLUS、PRO 100、PRO 200、PRO 500 使用独立颜色标签；支持深色、浅色和跟随系统主题。
- 设置中可选海洋蓝、暮光紫、青碧绿、落日橙四组渐变主题色；默认暮光紫，保留已保存的选择，修改设置时保留滚动位置。
- 手动重置前确认账号、次数和重置卡到期时间；请求结果不明确时停止重试，先刷新核对。
- 重置卡最早到期时间后用括号显示剩余倒计时，账号列表与重置确认页一致，并随时间更新。时间与图标按到期临近程度提醒：超过 3 天为绿色，超过 24 小时至 3 天为橙色，24 小时内为红色；3 天内加粗，未知时间保持灰色，已到期提示刷新。
- 添加账号时可选择浏览器授权、JSON 导入或获取本地已登录的账号；支持粘贴文本或选择官方 `auth.json` 与兼容的账号 JSON 文件，导入成功自动关闭弹窗。
- Windows 当前用户安装，内置运行所需组件；首页检测新版后弹窗提醒，可跳过版本、暂不更新或更新并重启。

## 安装与使用

1. 安装并运行过 Codex Desktop，确认本机能够连接其服务。
2. 使用上方 GitHub 固定直链下载 `Star-Codex-Switcher-Setup-x64.exe`，双击安装；该地址始终提供最新正式版。需要指定版本时，可到 [Releases](https://github.com/evenstar-2273/star-codex-switcher/releases) 下载带版本号的安装包，例如 `Star-Codex-Switcher-1.0.11-Setup-x64.exe`。升级时运行安装包即可，保留已有账号和设置；不要把安装包作为主程序文件替换。
3. 打开工具，点击“添加账号”选择获取本地账号 / 浏览器授权 / JSON 导入。取消授权后，工具会结束本次登录并恢复操作；无需退出当前账号。切换前先完成或停止 Codex Desktop 内正在运行的任务。
4. 点击账号的“切换”，核对二次确认提示后继续。切换流程可能关闭并重启 Codex Desktop。

安装版面向 **Windows 10/11 x64**。不同机器仍需能连接 OpenAI 服务；Windows ARM、企业限制环境以及所有系统补丁组合并未全面验证。

历史便携版的 EXE 可直接运行，安装版则会建立固定安装目录、快捷方式和卸载入口。今后的常规分发与自动更新以安装版为主。

在设置中选择额度自动刷新间隔。自定义项提供带“分钟”单位的圆角整数输入框和明确的“保存”按钮，显示未保存、保存成功或失败状态；仍支持按回车或移开焦点保存，空值、非整数或超出 1–1440 的值不保存。下拉选择与菜单适配深浅主题。禁用仅停止定时刷新，首次加载、手动刷新和自动重置不受影响。

从 1.0.1 起，窗口标题、快捷方式和安装显示名称统一为 `Star Codex Switcher`，主程序为 `StarCodexSwitcher.exe`。新用户默认安装到 `%LOCALAPPDATA%\Programs\Star Codex Switcher`，也可在安装时选择路径；旧用户升级沿用已有安装位置。需要源码时，在对应 GitHub Release 下载自动提供的 **Source code (zip)** 或 **Source code (tar.gz)**；它们不是安装包。

## 账号数据与导入

账号数据保存在当前 Windows 用户的数据目录，通常是 `%LOCALAPPDATA%\Codex Account Switcher`，与安装目录分开。为兼容已有数据，重命名不会迁移这个目录；升级保留已导入账号、登录记录和已有设置。安装包不包含发布者账号。卸载后重装或换电脑前，仍建议自行备份账号数据。

从 1.0.7 起，配置的数据目录和 Codex 登录目录可以使用合法目录联接或符号链接：启动时解析到实际目录，导入、账号服务与切换使用同一位置。损坏链接及账号库内部的链接跳转仍会拒绝，并显示中文原因；没有保存账号本身不会触发存储错误。

导入支持单个账号、账号数组及 `{"accounts": [...]}` 包装形式。需要真实完整的登录字段；含 `***` 的脱敏预览无法用于登录。不要把账号 JSON、`auth.json`、访问令牌或刷新令牌提交到仓库、Issue 或公开截图中。具体支持范围与失败处理见 [实现说明](GUARDED-README.md)。

同一 Windows 用户从便携版迁移到安装版可复用原数据目录。换电脑需要重新登录或自行导入账号，不会通过 GitHub 同步账号。

## 订阅有效期

有效期优先采用当前登录信息 `id_token` 中尚未到期的订阅期末，悬停日期可查看来源。这个日期不是本次在线核验结果；它缺失、无效或已经到期时，才查询官方 `accounts_check`，必要时再查询该账号的 `subscriptions`。所有日期按本机时区显示，不固定加减时差，也不根据登录时间或“一个月”推算续费后的到期日。

订阅结果缓存 30 分钟；登录信息中的订阅期末到达后，下次后台刷新会跳过该缓存并在线查询。点击账号卡片或顶部“刷新”也可跳过缓存，但仍优先保留尚未到期的登录订阅期末。需要在线查询却无法确认日期时显示“待核验”；此前已在线核验且尚未到期的日期可保留为参考，并标注待核验。旧登录信息中的日期不能直接证明账号已过期。

## 更新

安装版从本仓库最新 Release 中的 `update-installed.json` 读取版本信息，下载对应版本的安装包并校验 SHA-256。用户确认更新后，工具交接给安装程序，更新完成后重新启动。更新本工具不等于更新 Codex Desktop。

启用自动检查后，启动时检查一次，此后每 60 分钟检查；同一版本本次运行只自动提醒一次。首页检测到新版本后会显示更新弹窗；在后台或正在处理账号操作时，提醒会延后显示。

- **跳过版本**：持久保存对这个版本的选择，下一个新版仍会提醒。
- **暂不更新**：本次运行不再重复提醒，重启工具后可再次提示。
- **更新并重启**：安装新版本并重新打开工具，保留已有账号、登录记录和设置。

在设置中手动“检查更新”，仍可查看并安装已经跳过的版本。

更新源固定为本仓库，不在设置页提供自定义服务器地址。软件内新版本提示、[更新记录](CHANGELOG.md) 和 Release 说明对应同一版本。从 1.0.7 起，每次发布提供带版本号的安装包、其校验文件、更新清单和固定名安装包四项资产；固定名包与该版本包内容完全一致。软件自动更新仍使用清单中绑定具体版本的下载地址；源码使用 GitHub 自带的 Source code，详见 [发布文档](docs/windows-build-release.md)。

后续版本仅发布到 GitHub，保留历史 Release、下载资产和 tag；Latest、GitHub 固定下载直链和自动更新指向最新验证通过的版本。每次 GitHub 新版安装包、固定直链、校验文件和更新清单验证成功后，本地交付及测试打包目录只保留最新版安装包、对应校验文件及固定名副本。源码、源码归档、Git 历史及账号数据保留；发布或 GitHub 验证失败时不清理本地旧包。

服务器现有 1.0.8 安装包可保留为历史镜像，后续不再同步或验证，其固定入口不再保证提供最新版。服务器状态不影响 GitHub 发布、本地旧包清理或软件自动更新。
