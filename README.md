# Star Codex Switcher

面向 Windows 的 Codex 账号管理与切换工具。支持账号额度查看、JSON 导入和安装版更新，只维护 Codex 场景。

[下载安装包](https://github.com/evenstar-2273/star-codex-switcher/releases/latest) · [问题反馈](https://github.com/evenstar-2273/star-codex-switcher/issues) · [更新记录](CHANGELOG.md) · [构建与发布](docs/windows-build-release.md)

应用提供原生 Windows 界面，账号数据保存在本机，切换前检查目标凭据并要求二次确认。

## 功能

- 管理多个 ChatGPT 登录账号，切换前二次确认，并检查目标凭据是否可用。
- 显示剩余额度、重置时间、订阅有效期和重置次数；额度与临近到期状态用不同颜色区分。
- 订阅有效期通过官方账号与订阅接口在线核验；旧登录快照不能确认当前到期日时显示“待核验”。
- 根据账号接口返回的额度窗口显示 5 小时或每周额度，兼容只返回周额度的账号。
- 支持调整窗口大小；账号卡片按宽度排列为一至三列，切换、刷新、重置和删除直接放在列表中。
- FREE、PLUS、PRO 100、PRO 200、PRO 500 使用独立颜色标签；支持深色、浅色和跟随系统主题。
- 设置中可选海洋蓝、暮光紫、青碧绿、落日橙四组渐变主题色，立即应用并保存选择。
- 手动重置前确认账号、次数和机会到期时间；请求结果不明确时停止重试，先刷新核对。
- 从文本粘贴或文件导入官方 `auth.json` 与兼容的账号 JSON；导入成功自动关闭弹窗。
- Windows 当前用户安装，内置运行所需组件；从本仓库 GitHub Releases 检查更新，确认后安装并重新启动工具。

## 安装与使用

1. 安装并运行过 Codex Desktop，确认本机能够连接其服务。
2. 在 [Releases](https://github.com/evenstar-2273/star-codex-switcher/releases) 下载文件名包含 `Setup-x64.exe` 的安装包并运行。它是安装程序，不能把它直接覆盖到旧版程序上。
3. 打开工具，保存当前账号或导入账号 JSON。切换前先完成或停止 Codex Desktop 内正在运行的任务。
4. 点击账号的“切换”，核对二次确认提示后继续。切换流程可能关闭并重启 Codex Desktop。

安装版面向 **Windows 10/11 x64**。不同机器仍需能连接 OpenAI 服务；Windows ARM、企业限制环境以及所有系统补丁组合并未全面验证。

历史便携版的 EXE 可直接运行，安装版则会建立固定安装目录、快捷方式和卸载入口。今后的常规分发与自动更新以安装版为主。

## 账号数据与导入

账号数据保存在当前 Windows 用户的数据目录，通常是 `%LOCALAPPDATA%\Codex Account Switcher`，与安装目录分开。升级不会把发布者的账号带入安装包，也不应删除已有账号。卸载后重装或换电脑前，仍建议自行备份账号数据。

导入支持单个账号、账号数组及 `{"accounts": [...]}` 包装形式。需要真实完整的登录字段；含 `***` 的脱敏预览无法用于登录。不要把账号 JSON、`auth.json`、访问令牌或刷新令牌提交到仓库、Issue 或公开截图中。具体支持范围与失败处理见 [实现说明](GUARDED-README.md)。

同一 Windows 用户从便携版迁移到安装版可复用原数据目录。换电脑需要重新登录或自行导入账号，不会通过 GitHub 同步账号。

## 订阅有效期

有效期先查询官方 `accounts_check`，没有可确认的未来到期日时，再查询该账号的 `subscriptions`。显示服务端返回的日期和本地时间，不根据旧 JWT、登录时间或“一个月”推算续费后的到期日。

订阅查询结果缓存 30 分钟。点击账号卡片的刷新按钮或顶部“刷新”可跳过缓存重新核验。网络失败、凭据失效或官方接口未返回有效期时显示“待核验”；此前已核验且尚未到期的日期可保留为参考，并标注待核验。旧登录信息中的日期不能直接证明账号已过期。

## 更新

安装版从本仓库最新 Release 中的 `update-installed.json` 读取版本信息，下载对应版本的安装包并校验 SHA-256。用户确认更新后，工具交接给安装程序，更新完成后重新启动。更新本工具不等于更新 Codex Desktop。

更新源固定为本仓库，不在设置页提供自定义服务器地址。发布版本时必须同时上传安装包、校验文件和更新清单，详见 [发布文档](docs/windows-build-release.md)。
