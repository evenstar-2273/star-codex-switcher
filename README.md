# Star Codex Switcher

面向 Windows 的 Codex 账号管理与切换工具。支持账号额度查看、JSON 导入和安装版更新，只维护 Codex 场景。

[下载安装包](https://github.com/evenstar-2273/star-codex-switcher/releases/latest) · [问题反馈](https://github.com/evenstar-2273/star-codex-switcher/issues) · [更新记录](CHANGELOG.md) · [构建与发布](docs/windows-build-release.md)

应用提供原生 Windows 界面，账号数据保存在本机，切换前检查目标凭据并要求二次确认。

## 功能

- 管理多个 ChatGPT 登录账号，切换前二次确认，并检查目标凭据是否可用。
- 显示剩余额度、恢复时间、订阅有效期和重置次数；恢复时间后用括号显示剩余倒计时，额度与临近到期状态用不同颜色区分。
- 优先显示当前登录信息中尚未到期的订阅期末；缺失或过期后通过官方接口查询，无法确认时显示“待核验”。
- 根据账号接口返回的额度窗口显示 5 小时或每周额度，兼容只返回周额度的账号。
- 支持调整窗口大小；账号卡片按可用宽度自动增减列数，切换、刷新、重置和删除直接放在列表中。
- 手动全量刷新时，顶部与所有卡片的刷新图标旋转；单卡刷新仅旋转对应图标，实际请求完成或失败后停止，防止重复请求并保持滚动位置。
- FREE、PLUS、PRO 100、PRO 200、PRO 500 使用独立颜色标签；支持深色、浅色和跟随系统主题。
- 设置中可选海洋蓝、暮光紫、青碧绿、落日橙四组渐变主题色；默认暮光紫，保留已保存的选择，修改设置时保留滚动位置。
- 手动重置前确认账号、次数和机会到期时间；请求结果不明确时停止重试，先刷新核对。
- 重置机会最早到期时间与图标同步提醒：超过 3 天为绿色，超过 24 小时至 3 天为橙色，24 小时内为红色；3 天内加粗，未知时间保持灰色，已到期提示刷新。卡片与重置确认规则一致。
- 添加账号时可选择浏览器授权或 JSON 导入；支持粘贴文本或选择官方 `auth.json` 与兼容的账号 JSON 文件，导入成功自动关闭弹窗。
- Windows 当前用户安装，内置运行所需组件；首页检测新版后弹窗提醒，可跳过版本、暂不更新或更新并重启。

## 安装与使用

1. 安装并运行过 Codex Desktop，确认本机能够连接其服务。
2. 在 [Releases](https://github.com/evenstar-2273/star-codex-switcher/releases) 下载对应版本的安装包，例如 `Star-Codex-Switcher-1.0.4-Setup-x64.exe`，双击安装。它是安装程序，不能把它直接覆盖到旧版程序上。
3. 打开工具，保存当前账号，或点击“添加账号”选择浏览器授权 / JSON 导入。取消授权后，工具会结束本次登录并恢复操作；无需退出当前账号。切换前先完成或停止 Codex Desktop 内正在运行的任务。
4. 点击账号的“切换”，核对二次确认提示后继续。切换流程可能关闭并重启 Codex Desktop。

安装版面向 **Windows 10/11 x64**。不同机器仍需能连接 OpenAI 服务；Windows ARM、企业限制环境以及所有系统补丁组合并未全面验证。

历史便携版的 EXE 可直接运行，安装版则会建立固定安装目录、快捷方式和卸载入口。今后的常规分发与自动更新以安装版为主。

从 1.0.1 起，窗口标题、快捷方式和安装显示名称统一为 `Star Codex Switcher`，主程序为 `StarCodexSwitcher.exe`。新用户默认安装到 `%LOCALAPPDATA%\Programs\Star Codex Switcher`，也可在安装时选择路径；旧用户升级沿用已有安装位置。需要源码时下载 `Star-Codex-Switcher-1.0.4-source.zip`，它不是安装包。

## 账号数据与导入

账号数据保存在当前 Windows 用户的数据目录，通常是 `%LOCALAPPDATA%\Codex Account Switcher`，与安装目录分开。为兼容已有数据，重命名不会迁移这个目录；升级保留已导入账号、登录记录和已有设置。安装包不包含发布者账号。卸载后重装或换电脑前，仍建议自行备份账号数据。

导入支持单个账号、账号数组及 `{"accounts": [...]}` 包装形式。需要真实完整的登录字段；含 `***` 的脱敏预览无法用于登录。不要把账号 JSON、`auth.json`、访问令牌或刷新令牌提交到仓库、Issue 或公开截图中。具体支持范围与失败处理见 [实现说明](GUARDED-README.md)。

同一 Windows 用户从便携版迁移到安装版可复用原数据目录。换电脑需要重新登录或自行导入账号，不会通过 GitHub 同步账号。

## 订阅有效期

有效期优先采用当前登录信息 `id_token` 中尚未到期的订阅期末，悬停日期可查看来源。这个日期不是本次在线核验结果；它缺失、无效或已经到期时，才查询官方 `accounts_check`，必要时再查询该账号的 `subscriptions`。所有日期按本机时区显示，不固定加减时差，也不根据登录时间或“一个月”推算续费后的到期日。

订阅结果缓存 30 分钟；登录信息中的订阅期末到达后，下次后台刷新会跳过该缓存并在线查询。点击账号卡片或顶部“刷新”也可跳过缓存，但仍优先保留尚未到期的登录订阅期末。需要在线查询却无法确认日期时显示“待核验”；此前已在线核验且尚未到期的日期可保留为参考，并标注待核验。旧登录信息中的日期不能直接证明账号已过期。

## 更新

安装版从本仓库最新 Release 中的 `update-installed.json` 读取版本信息，下载对应版本的安装包并校验 SHA-256。用户确认更新后，工具交接给安装程序，更新完成后重新启动。更新本工具不等于更新 Codex Desktop。

启用自动检查后，启动时检查一次，此后每 60 分钟检查；同一版本本次运行只自动提醒一次。首页检测到新版本后会显示更新弹窗；在后台或正在处理账号操作时，提醒会延后显示。

- **跳过版本**：持久保存对这个版本的选择，下一个新版仍会提醒。
- **暂不更新**：本次运行不再重复提醒，重启工具后可再次提示。
- **更新并重启**：安装新版本并重新打开工具，保留已有账号、登录记录和设置。

在设置中手动“检查更新”，仍可查看并安装已经跳过的版本。

更新源固定为本仓库，不在设置页提供自定义服务器地址。软件内新版本提示、[更新记录](CHANGELOG.md) 和 Release 说明对应同一版本。发布时同步上传安装包、源码包、校验文件与更新清单，详见 [发布文档](docs/windows-build-release.md)。
