# Star Codex Switcher

本分支的中文说明统一维护在 [README.md](README.md)。

本项目提供 Windows 版 Codex 账号管理、切换和安装更新。

订阅有效期优先保留当前登录信息中尚未到期的订阅期末，缺失或过期后再通过官方接口查询，来源会如实标注。结果缓存 30 分钟，手动刷新及登录期末到达后的后台刷新可跳过缓存。完整使用说明见 [订阅有效期](README.md#订阅有效期)，合成测试命令见 [构建与发布](docs/windows-build-release.md)。

Windows 应用、安装程序与托盘采用本分支选定的 S 形双箭头与星标图标，详见 [图标资源说明](docs/branding.md)。
