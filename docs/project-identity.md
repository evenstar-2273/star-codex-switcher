# 项目信息

| 项目 | 内容 |
| --- | --- |
| 名称 | Star Codex Switcher |
| 仓库维护者 | evenstar-2273 |

| 发布平台 | Windows 10/11 x64 |

Star Codex Switcher 提供 Codex 账号管理、额度查看、订阅有效期核验、JSON 导入、手动确认切换与安装版更新。账号数据存储在当前 Windows 用户的数据目录，更新程序与账号数据分开。

功能、安装要求与限制以 [README](../README.md) 和 [Windows 实现说明](../GUARDED-README.md) 为准。Windows 安装包、更新清单与校验文件在同一 Release 发布。
