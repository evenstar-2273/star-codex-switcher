# Windows 应用结构

## 组件

- `Sources/SwitcherCore` 保存账号模型、存储、RPC、额度处理与账号核心逻辑。
- `Sources/SwitcherHost` 将核心包装为随应用启动的子进程，通过私有标准输入/输出协议交换命令与状态。
- `windows/CodexAccountSwitcher.Core` 提供 Windows 进程适配、在线凭据检查、JSON 导入、额度/订阅查询、手动重置与切换保护。
- `windows/CodexAccountSwitcher` 提供 WPF 界面、主题、托盘、开机启动与更新交接。
- `windows/installer` 提供当前用户安装、升级、快捷方式与卸载。

账号凭据保存在当前用户目录，应用安装目录与账号数据目录分开。核心随 UI 启动，不是独立 HTTP 服务。安装包附带所需运行时，用户不需要配置开发工具链。

## 切换顺序

用户确认目标账号后，先在线检查其凭据；随后关闭匹配的 Codex Desktop 进程及子进程，保存和写入目标状态，再验证目标登录并启动桌面。关闭、凭据或验证失败时停止后续动作，按已知状态进行有限恢复，不覆盖第三个程序刚写入的身份。

独立启动的 CLI 会话与无关的同名程序不属于桌面关闭目标。切换可能中断 Codex Desktop 内正在运行的任务，因此界面保留二次确认。

## 查询与刷新

官方用量、订阅和重置卡分别读取。用量决定可显示的 5 小时/每周窗口；订阅查询用于核验实际到期日；重置卡最早到期不等于额度自动恢复时间。读取失败和未知状态在 UI 中明确区分，不能当作 0 或已经过期。

具体请求和失败处理见 [实现说明](../GUARDED-README.md)，构建与合成测试见 [构建文档](windows-build-release.md)。
