# Windows 验证范围

本项目面向 Windows 10/11 x64。验证分为核心逻辑、原生界面、打包与安装三个层次，不能用其中一项代替其它层。

## 核心与界面

合成检查覆盖凭据验证、导入、切换失败恢复、目标桌面进程识别、额度窗口、套餐识别、订阅日期、重置次数，以及更新清单和安装交接。

界面检查覆盖深色、浅色、跟随系统、1—3 列卡片、窄屏滚动、切换与重置二次确认、成功导入后关闭弹窗，以及当前账号禁止删除。图标检查覆盖原图、透明角、多尺寸 ICO 和可见度。具体截图和本次检查记录见 [界面验证](../design-qa.md)。

测试使用隔离目录和合成数据，不自动切换开发者的真实账号，不执行真实额度消费。桌面进程测试使用独立夹具，不终止用户的 Codex Desktop。

## 安装与发布

安装包附带应用和运行时。应分别检查无开发环境运行、首次安装、升级保留数据、更新后启动、卸载，以及 Release 下载后的版本与哈希。

编译、合成测试、安装测试和公开下载属于不同验证结果。以 [构建与发布](windows-build-release.md) 的命令及当前 Release 记录为准，不保留旧构建的大小、哈希或测试数量作为当前版本结论。
