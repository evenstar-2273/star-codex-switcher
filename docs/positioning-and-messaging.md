# 产品定位与说明

## 使用场景

需要在多个已授权 Codex 账号间切换的 Windows 用户，可先查看额度、订阅有效期与重置卡，再确认切换。界面提供直接添加、粘贴或文件导入，以及逐账号刷新和管理。

## 对外简述

Star Codex Switcher 是面向 Windows 的 Codex 账号管理与切换工具，支持额度查看、JSON 导入、深浅主题和安装版更新。

## 描述边界

- 发布平台为 Windows 10/11 x64。
- 用户选择目标账号并再次确认切换；额度刷新不会自动轮换账号。
- 套餐、额度和订阅到期日以读取结果为准。无法在线核验的到期日显示待核验，不推算续费日期。
- 更新保留账号数据，但换电脑仍需自行登录或导入。
- 性能、安装包大小、代码签名和兼容性结论应以对应 Release 的实际检查为准。
- 不公开真实账号 JSON、令牌、邮箱或诊断日志。

## 发布内容

发布说明写清本次变化、验证结果和已知限制，下载地址指向本仓库 Release。安装版与便携版名称应明确区分，不能把 Setup EXE 当作应用 EXE 覆盖。
