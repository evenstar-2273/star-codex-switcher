# Windows 测试

测试命令统一维护在 [构建与发布](windows-build-release.md)。检查使用合成账号、隔离的临时目录和受控 HTTP/RPC 响应，不切换真实账号或消耗真实重置卡。

## 主要检查

- 凭据解析、身份匹配、失效凭据和切换失败恢复。
- JSON 单账号、数组和包装格式导入；当前账号保护。
- 5 小时/每周额度、套餐细分等级、重置卡和到期字段。
- 官方订阅查询、旧快照待核验、30 分钟缓存和手动刷新。
- 深浅主题、跟随系统、响应式卡片、二次确认和导入窗口。
- 更新清单、下载限制、哈希、安装版本和更新交接。
- 安装包首次安装、升级保留数据、启动与卸载。

测试通过不代替真实环境验收。网络代理、权限、杀毒软件、Windows 版本与 Codex Desktop 的进程行为需要在相应发布环境中检查。

## 视觉证据

界面截图由原生 WPF 控件使用合成账号渲染，验证方法与结果见 [界面验证记录](../design-qa.md)。截图不包含系统标题栏，不能代替 EXE 或安装程序外壳的图标检查。

## 发布前

以本次 tag 和安装包为对象重新检查版本与 SHA-256。下载、安装和更新成功以实际执行结果为准，不把本地编译、测试夹具或生成截图当作公开发布成功。
